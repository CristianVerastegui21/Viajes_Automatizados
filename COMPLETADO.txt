🚀 CÓMO USAR
================================================================================

1. INSTALAR DEPENDENCIAS:
   $ pip install -r requirements.txt

2. EJECUTAR SERVIDOR (Terminal 1):
   $ python travel_ai_server.py
   ✅ Espera a ver: "Uvicorn running on http://0.0.0.0:8002"

3. EJECUTAR APLICACIÓN (Terminal 2):
   $ streamlit run travel_app.py
   ✅ Se abrirá en http://localhost:8501

4. USAR LA APLICACIÓN:
   - Completa los datos en el panel lateral
   - Haz clic en "🚀 Buscar Mejores Ofertas con IA"
   - Ve a la pestaña "🎯 Ofertas"
   - Haz clic en los botones de descarga

5. VER ESTADÍSTICAS:
   - Ve a la pestaña "📊 Estadísticas"
   - Observa métricas y gráficos

6. PROBAR REPORTES:
   $ python test_reports.py
