🔌 ENDPOINTS API DISPONIBLES
================================================================================

POST /download-report
  - Descargar reportes en PDF o Excel
  - Parámetros: travel_data, report_type, format

GET /statistics
  - Obtener estadísticas del sistema
  - Respuesta: JSON con métricas

  - Parámetros: flight_data, hotel_data, user_preferences

GET /docs
