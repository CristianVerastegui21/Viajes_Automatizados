🆘 SOLUCIÓN DE PROBLEMAS
================================================================================

PROBLEMA: "Connection refused"
SOLUCIÓN: Asegúrate de que el servidor está ejecutándose en Terminal 1

PROBLEMA: "ModuleNotFoundError"
SOLUCIÓN: Ejecuta: pip install -r requirements.txt

PROBLEMA: "Puerto ocupado"
SOLUCIÓN: Cambia el puerto en config.py

PROBLEMA: Streamlit no carga
SOLUCIÓN: Verifica que el servidor FastAPI está ejecutándose
